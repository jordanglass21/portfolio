# portfolio

Personal portfolio site for Jordan Glass. Built with Next.js (App Router), TypeScript, and Tailwind CSS, deployed on Vercel.

## Development

```bash
npm install
npm run dev        # local dev server at http://localhost:3000
npm run lint       # ESLint
npm run typecheck  # tsc --noEmit
npm run build      # production build
```

See [`SPEC.md`](./SPEC.md) for the full spec and [`CLAUDE.md`](./CLAUDE.md) for project conventions.
